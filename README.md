# Credit Card Fraud Detection

Machine Learning-based Credit Card Fraud Detection system with Power BI dashboard, PostgreSQL integration, and real-time prediction.

## Setup Instructions
1. Virtual environment banayein: `python -m venv venv`
2. Requirements install karein: `pip install -r requirements.txt`
3. PostgreSQL setup karein aur `sql/schema.sql` ko run karke table banayein.
4. Model ko train karke `models/` folder me `fraud_model.pkl` naam se save karein.
5. App run karein: `streamlit run app.py`
